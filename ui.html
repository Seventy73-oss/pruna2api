接口清单

方法路径说明
POST/v1/videos/generations提交生成（视频/图片模型通用）
POST/v1/videos同上（OpenAI Sora 风格别名）
POST/v1/images/generations图片生成（完整 OpenAI 参数：size / n / response_format）
GET/v1/tasks/{id}查单个任务（status 为 OpenAI 语义）
GET/v1/tasks?limit=&status=列任务
GET/v1/models列模型与免费额度
GET/v1/exits出口池状态（IP / 冷却 / 失败次数）
POST/v1/exits/probe重新探测全部出口的真实 IP（约 25s）
GET/files/{name}下载成品（本地转存，不过期）
GET/health健康检查
OpenAI 兼容用法 
# 图片接口支持 OpenAI 标准参数：size / n / response_format
curl -X POST http://127.0.0.1:3020/v1/images/generations \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "p-image",
    "prompt": "a wide cinematic landscape",
    "size": "1792x1024",
    "n": 1,
    "response_format": "url"
  }'

# 响应就是 OpenAI 形状：
#   {"created":1789..., "model":"p-image", "status":"completed",
#    "data":[{"url":"http://127.0.0.1:3020/files/task_xxx.jpg"}],
#    "exit":{"name":"us01","egress_ip":"203.0.113.10"}}
#
# size 会映射成 Pruna 的宽高比（1792x1024 → 16:9，实测输出 1344x768）
# response_format 改 "b64_json" 则 data[0].b64_json 给 base64，且不再返回 url
# n 上限 4（每张各扣一次配额）

# 视频走 Sora 风格路径，返回体带 job 语义的 status
curl -X POST http://127.0.0.1:3020/v1/videos \
  -H 'Content-Type: application/json' \
  -d '{"model":"p-video-2-pro","prompt":"a cat","wait":false}'

# 错误统一为 OpenAI 顶层形状：
#   {"error":{"message":"...","type":"invalid_request_error","param":"n","code":"..."}}
文生视频 
curl -X POST http://127.0.0.1:3020/v1/videos/generations \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "p-video-2-pro",
    "prompt": "a cat sitting on a windowsill, morning light, cinematic",
    "aspect_ratio": "16:9",
    "resolution": "768p",
    "duration": 5,
    "mode": "speed",
    "wait": true
  }'
图生视频（dataURL） 
# base64 编码后拼成 dataURL
B64=$(base64 -w0 photo.jpg)

curl -X POST http://127.0.0.1:3020/v1/videos/generations \
  -H 'Content-Type: application/json' \
  -d "{
    \"model\": \"p-video-2-pro\",
    \"image\": \"data:image/jpeg;base64,$B64\",
    \"prompt\": \"the camera slowly zooms in\",
    \"wait\": true
  }"
视频转视频 
# p-video-animate / p-video-replace 的参考图为必填
# p-video-edit 可选，且可用 images 数组传多张
curl -X POST http://127.0.0.1:3020/v1/videos/generations \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "p-video-animate",
    "video": "https://example.com/source.mp4",
    "image": "https://example.com/ref.jpg",
    "prompt": "make it dance",
    "wait": true
  }'
